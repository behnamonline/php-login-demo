# سیستم لاگین ساده با PHP و SQLite (آموزشی)

## اجرا

نیاز: PHP 8 با افزونه‌ی pdo_sqlite

```
cd php-login-demo
php -S localhost:8000
```

بعد برو به http://localhost:8000
(فایل دیتابیس و جدول‌ها خودکار توی پوشه‌ی `db/` ساخته میشن.)

## ساختار فایل‌ها

| فایل | کار |
|---|---|
| config.php | اتصال دیتابیس، ساخت جدول‌ها، ساخت و بررسی توکن |
| header.php / footer.php | قالب مشترک صفحه‌ها |
| index.php | صفحه‌ی اصلی |
| signup.php | ثبت نام (پسورد با password_hash هش میشه) |
| login.php | ورود، ساخت توکن |
| dashboard.php | داشبورد چند صفحه‌ای (`?page=profile` و `?page=addItem`) |
| profile.php | API: بررسی توکن و برگردوندن یوزر |
| addItem.php | API: لیست آیتم‌ها (GET) و افزودن آیتم (POST) |

## جریان کار

1. ثبت نام: یوزر با پسورد هش‌شده توی جدول `users` ذخیره میشه.
2. ورود: پسورد با `password_verify` چک میشه، توکنی به فرمت `user_id|رشته_رندوم` به مرورگر داده میشه و مرورگر اون رو توی `localStorage` نگه می‌داره. توی جدول `tokens` فقط هش sha256 بخش رندوم ذخیره میشه.
3. داشبورد: برای هر درخواست، توکن توی هدر `X-Token` به `profile.php` و `addItem.php` فرستاده میشه.
4. سرور: عدد قبل از `|` رو به عنوان user_id می‌خونه، توی جدول `tokens` با user_id سرچ می‌کنه، بخش رندوم رو هش می‌کنه و با هش داخل دیتابیس مقایسه می‌کنه. اگه درست نبود یا منقضی شده بود، جواب `403` میده.

## چرا localStorage و نه کوکی؟

چون توکن باید با JavaScript توی هدر درخواست گذاشته بشه (`X-Token`). کوکی خودکار فرستاده میشه و نیازی به هدر دستی نداره، ولی برای این آموزش (نشون دادن هدر توکن) localStorage مناسب‌تره.

## نکات برای ادامه‌ی یادگیری

- توکن کامل (`2|6ddb...`) فقط توی localStorage مرورگر ذخیره میشه. توی دیتابیس فقط هش sha256 بخش رندوم نگه‌داری میشه.
- خروج فقط توکن رو از مرورگر پاک می‌کنه؛ توکن توی دیتابیس تا انقضا باقی می‌مونه.
- اعتبار توکن ۷ روزه (`TOKEN_LIFETIME` توی config.php).
